# Day 1 — Variables, data types and input/output

## Learning objective

The purpose of Day 1 is to build a strong foundation in programming before moving into data structures and algorithms.

Every DSA problem eventually requires you to:

- Store information.
- Read input.
- Process values.
- Perform calculations.
- Compare values.
- Convert values from one form to another.
- Produce the required output.

These operations depend on variables, data types, constants, expressions, input, and output.

By the end of Day 1, you should be able to write small programs from scratch without copying the structure of another program.

---

# 1. What is a variable?

A variable is a named location used by a program to store a value.

For example:

```python
age = 25
name = "Atul"
price = 99.50
```

Here:

| Variable | Value | Type |
|---|---:|---|
| `age` | `25` | Integer |
| `name` | `"Atul"` | String |
| `price` | `99.50` | Floating-point number |

A variable allows the program to remember information and use that information later.

For example:

```python
price = 100
quantity = 5

total = price * quantity

print(total)
```

Output:

```text
500
```

The program stores `100` in `price`, `5` in `quantity`, and then calculates `500`.

---

# 2. Variable naming

Good variable names make programs easier to understand.

Good examples:

```python
age = 25
student_name = "Atul"
total_marks = 450
temperature = 32.5
```

Poor examples:

```python
x = 25
a = "Atul"
q = 450
t = 32.5
```

Short names are sometimes useful in mathematical algorithms, but while learning, prefer descriptive names.

## Common naming rules

A variable name generally:

- Should describe the stored value.
- Should not contain spaces.
- Should not begin with a number.
- Should not use reserved programming keywords.
- Should use a consistent naming style.

Example:

```python
student_name = "Atul"
total_marks = 480
maximum_value = 100
```

Avoid:

```python
student name = "Atul"
2value = 100
```

# 3. Assigning values

The assignment operator is used to store a value in a variable.

```python
age = 25
```

This means:

> Store the value `25` in the variable named `age`.

Assignment is not the same as mathematical equality.

For example:

```python
x = 10
x = x + 5
```

After the second statement:

```text
x = 15
```

The old value of `x` is replaced by the new value.

# 7. Characters

A character represents a single symbol.

Examples:

```text
A
B
z
7
@
#
```

In some programming languages, characters have a dedicated `char` type.

For example, in C++:

```cpp
char grade = 'A';
```

In Python, there is no separate `char` data type. A single character is represented as a string containing one character:

```python
grade = "A"
```

This distinction is useful when learning multiple programming languages.

# 13. Why type conversion matters

Input entered by a user is commonly received as text.

For example:

```python
age = input("Enter your age: ")
```

Even if the user enters:

```text
25
```

the result is initially a string.

Therefore, numerical calculations usually require conversion:

```python
age = int(input("Enter your age: "))
```

Now the value can be used mathematically.

Example:

```python
age = int(input("Enter your age: "))

next_year_age = age + 1

print(next_year_age)
```

If the user enters:

```text
25
```

the output is:

```text
26
```

# 14. Constants

A constant is a value that is intended to remain unchanged during program execution.

Python does not enforce constants in the same way some other languages do. A common convention is to use uppercase names.

Example:

```python
PI = 3.141592653589793
DAYS_IN_WEEK = 7
```

The uppercase name communicates:

> This value is intended to remain unchanged.

Example:

```python
PI = 3.141592653589793
radius = 5

area = PI * radius * radius

print(area)
```

Constants become useful when the same fixed value is required in multiple places.

# 39. Common beginner mistakes

## Mistake 1 — Treating input as a number automatically

Incorrect:

```python
a = input()
b = input()

print(a + b)
```

If the input is:

```text
10
20
```

the result may be:

```text
1020
```

because both values are strings.

Correct:

```python
a = int(input())
b = int(input())

print(a + b)
```

Output:

```text
30
```

---

## Mistake 2 — Mixing incompatible types

Be careful when combining strings and numbers.

Instead of relying on implicit behavior, explicitly convert values when necessary.

Example:

```python
age = int(input())

print("Age:", age)
```

---

## Mistake 3 — Using the wrong division operator

Remember:

```python
/
```

produces normal division.

```python
//
```

performs floor division.

Example:

```python
print(10 / 3)
print(10 // 3)
```

Output:

```text
3.3333333333333335
3
```

---

## Mistake 4 — Forgetting operator precedence

For example:

```python
result = 10 + 5 * 2
```

Multiplication is performed before addition.

Result:

```text
20
```

If you want addition first:

```python
result = (10 + 5) * 2
```

Result:

```text
30
```

Use parentheses when they make the intended calculation clearer.

---

## Mistake 5 — Overwriting a variable accidentally

Example:

```python
price = 100
price = 50
```

The original value `100` is no longer stored in `price`.

Always understand when a variable is being updated.

# 44. Day 1 problem-solving habit

For every small problem, follow this process:

```text
Read the problem
      ↓
Identify the inputs
      ↓
Identify the required outputs
      ↓
Identify the data types
      ↓
Write the formula or logic
      ↓
Create variables
      ↓
Perform the calculation
      ↓
Display the result
      ↓
Test with sample input
      ↓
Test with another input
```

Do not immediately start writing code.

First determine:

```text
What information do I receive?
What information do I need to produce?
What calculations are required?
What type should each value have?
```

This habit will become increasingly important as DSA problems become more complex.
